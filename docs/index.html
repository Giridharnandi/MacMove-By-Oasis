What’s supported — and what’s still a work in progress +

Images: PNG, JPEG, HEIC, TIFF, BMP, WebP, AVIF and SVG input routes. Select several files and convert them together to a common destination format. Availability depends on the destination codec. PNG → HEIC has been confirmed in the normal Mac app. WebP has a built-in lossless fallback; AVIF depends on an available codec.

PDF & text: merge, split, page organization, text/image extraction, text-to-PDF and some DOCX routes. No universal Office converter or OCR.

Media & subtitles: audio/video conversion and editing; SRT, VTT and text. Many routes need a separately installed FFmpeg. Codec support varies.

Limits: native image loading is limited to 100 MB and 40 megapixels. Archive conversion is disabled. Background framing does not remove backgrounds. Redaction and metadata tools are not certified anonymization tools. Not every route has been tested end to end.

No Terminal required for the download.

  1. Download & install

    Open the MacMove installer package and follow the steps. It places the app in Applications.

  2. Open MacMove

    When installation finishes, open MacMove from Applications. To update, run the newer installer; it replaces the existing app.

  3. Open it & check the menu bar

    MacMove by Oasis lives in the menu bar. Drag a file and use Shift for conversion, Command for tools, or Control for actions.

Having trouble opening the installer? +

Click Done, then open System Settings → Privacy & Security. If the warning says Apple cannot check the app or the developer cannot be verified, review Apple’s opening guidance. Only if you trust the exact download, use the per-app Open Anyway option in System Settings → Privacy & Security, if available.

If the installer is reported as damaged or contains malware, do not bypass the warning. Report the exact message.

A FEW GOOD QUESTIONS

Before you
take a bite.

Is it really free? +

Yes. MacMove by Oasis has no account, subscription or conversion quota. Its source is licensed under GPL-3.0-only. Optional third-party tools have their own licenses.

How do updates work? +

The app checks GitHub for a published release and opens this download page with your app version. This page tells you whether a newer version is available. Download and open the newer installer. It replaces the existing app after you confirm in Installer.

Will it work on every Mac? +

This trial targets macOS 26 or later on Apple silicon. Intel Macs are not currently verified. Some tools depend on optional FFmpeg and available codecs.

Who makes MacMove? +

MacMove by Oasis is built on Satsuma, with its original MIT attribution preserved.

Can I help build it? +

Please do. Report a reproducible issue or propose a focused improvement on GitHub. Avoid uploading private files to public issues.
