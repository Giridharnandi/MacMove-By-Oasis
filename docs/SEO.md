# Search and AI discovery

Implemented: static semantic HTML, unique title/description/canonical per page, Open Graph/Twitter cards, local PNG preview, descriptive links, accessible controls, index/follow metadata, linked XML sitemap, SoftwareApplication/SoftwareSourceCode + Organization + WebSite JSON-LD, GPL license and source links, and llms.txt facts/limitations. No fake reviews, ratings, keyword stuffing or guarantees of rankings. All core copy is readable without JavaScript. The optional release check degrades to a GitHub link.

The checklist follows the retrieved Someone.help SEO guidance: technical metadata, sitemap/robots/canonicals, headings/links, schema validation, AI-search citability and rendered-page inspection. No claim is made that Core Web Vitals have field measurements or that the site has been indexed.

The public site is intended to use https://oasis.upfaast.com/. The host must serve robots.txt and sitemap.xml from its root. The included robots.txt is suitable for the dedicated hostname. Pages have no noindex directives; the host must also allow crawling. Submit the sitemap through the owner's Search Console/Bing tools after verification if desired; no submission has been claimed. llms.txt is a supplemental convention, not a ranking or inclusion requirement.
