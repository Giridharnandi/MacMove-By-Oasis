# Privacy policy

**Last updated:** 19 October 2026  
**Applies to:** MacMove by Oasis for macOS and the MacMove download website.

This repository copy describes the current product. The [website privacy policy](https://oasis.upfaast.com/privacy.html) is also available online.

## Files and the Mac app

MacMove processes selected files locally with macOS frameworks and, for some operations, separately installed tools such as FFmpeg. Oasis does not operate a file-upload or cloud-conversion service. Results are saved to the destination you choose; temporary files may be created while processing. You control the source files and outputs.

The current app has no account system, advertising SDK, app analytics, or automatic crash-report upload. Diagnostic logging is off by default. If enabled for troubleshooting, local logs may contain file names, paths, operation details, and errors. Review and redact logs before sharing them.

## Update checks and locally stored settings

The app checks GitHub for published releases. Automatic checks run no more than once per day after a successful check; manual checks open the download page when requested. Update requests do not include files or file names. When the app opens the download page, its version is included in the URL so the page can compare versions.

The app stores its settings and the time of its last successful update check locally. These values are not sent with update checks.

## Website hosting and request data

GitHub hosts the repository, releases, and download website. Like other websites, GitHub may receive request data such as IP address, browser or user-agent information, requested URLs, and request times. GitHub's own privacy, logging, and retention practices apply; see [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The download page requests the latest release information from GitHub to display available downloads. A download-button click does not prove that a file was fully downloaded or installed. GitHub also provides aggregate release download and repository traffic counts; these can include repeat requests and project testing.

## Optional website analytics

Website analytics are optional and remain off unless you choose **Allow analytics**. If allowed, the website sends page views, GitHub-link clicks, and download-button clicks to the project's GoatCounter instance, hosted on Railway. The analytics integration does not use PostHog or share the Some1.help analytics project.

Events may include the page path, referring website domain or a simple `utm_source` campaign label, event type, and release version for installer clicks. Full query strings, referrer paths, files, file names, form text, and screen recordings are not sent by the integration.

GoatCounter receives the request IP address and browser information to estimate visits and approximate country. Its analytics database does not store raw IP addresses. The hosting provider may retain ordinary request logs under its own policies. Counts are estimates, not identified people. See [GoatCounter's privacy documentation](https://www.goatcounter.com/help/privacy) and [Railway's privacy policy](https://railway.com/legal/privacy).

## Your analytics choice

Analytics are off until you allow them. **No thanks** keeps them off. The website respects Do Not Track and Global Privacy Control. Use **Analytics preferences** in the footer to withdraw your choice and stop future events.

The website stores only your choice and its expiry in browser storage for up to 180 days. The integration does not set analytics cookies or save a visitor or session identifier. Older integration identifiers are removed when the current version loads. If browser storage is unavailable, your choice lasts only for that page. Withdrawing consent does not erase events already collected; contact us to ask about deletion.

## Information you choose to share

GitHub issues, pull requests, and discussions may be public. Do not post private files, passwords, identifying documents, or unredacted logs. If you contact Oasis, information you provide is used to respond and maintain the project. Information submitted to Oasis is not sold.

Links to GitHub, Instagram, and other external services take you to services Oasis does not control; their own privacy policies apply.

## Your choices and questions

You can stop using the app or website, remove the app and its locally stored settings, and delete local logs and outputs. For privacy questions or deletion requests about information you sent to Oasis, contact [sintaxerror.pvt.ltd@gmail.com](mailto:sintaxerror.pvt.ltd@gmail.com). Questions about GitHub account or hosting records should be directed to GitHub.

This policy may be updated when the product's data practices change.
